# Blynk
A feature-rich LED controller

> [!NOTE]
> This board runs on [WLED firmware](https://kno.wled.ge/)

## Features:
- Powered by an ESP32 S3
- ICS-43434 microphone
- Plus line-in with ES7243
- Low-profile PIR for motion detection
- IR receiver with custom remote control
- BH1750 ambient light sensor
- Full RGBW CCT support
- Reverse polarity protection and automatic supply switching
